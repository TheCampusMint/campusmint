# iPhone functional checklist — November 1, 2026

Compare the installed build with https://www.thecampusmint.com using the same account. No screenshot-by-screenshot review is required. These are checks to perform, not checks the agent claims you have already passed.

- [ ] Relaunch the app and confirm the same account/profile returns. Edit your bio/major, then check the website. Log out and back in; confirm those edits remain.
- [ ] Set a profile field to Only me; verify from a different account that it is hidden. Change it back and check both devices. Do not use your own signed-in view to test someone else's privacy.
- [ ] In a separate eligible test account, verify signup keeps First name, Last name and Username separate and resumes setup after closing/reopening.
- [ ] Publish text, a poll, a photo and a short video. Try camera capture. Reopen a saved draft. Shape should remain intact, and a failed connection should keep the draft instead of pretending it posted.
- [ ] Add/remove a Club or Event context, an @ mention and a hashtag. Confirm only joined Clubs are selectable and deselecting removes their attachment.
- [ ] Appreciate, endorse and save a post. Refresh the other device. Open Profile → Saved posts and reopen it. Try Not interested and confirm it leaves the feed.
- [ ] Add/reply/like/delete a test comment; confirm the visible count changes and the other device updates. Turn comments off using available web controls and confirm native posting is unavailable.
- [ ] Find a person, open their profile, follow/unfollow and start a message. Test block/unblock and verify blocked content/conversation access disappears.
- [ ] Send/reply/read a text DM on one device and check the other. Test older-message history and inbox pinning.
- [ ] Open Add note in dark mode, edit/save, then reopen it. It should float, stay dark, and close by tapping outside. No music option should appear.
- [ ] Open a message/follow/Club/Event notification and check its destination. Mark notifications read and check the other device.
- [ ] Create a private test Club. With a second account, request membership; approve it, invite someone, edit the page, and test owner/admin/member permissions.
- [ ] Post a test marketplace item. Message as a buyer, reply as the seller, switch buyer threads, then mark sold/available. Other buyers must not see someone else's messages.
- [ ] Open an available campus Event, change Going, and check the website. Share a public item to someone signed out; they should see only the shared item.
- [ ] Cancel one share sheet, then complete another share. Neither should create a second post or unexpectedly leave the app stuck.
- [ ] Choose/deny location in Search; Food/Events/Sell should retain a usable campus fallback. Google ratings/photos remain unavailable until its key is configured.
- [ ] Choose Sports interests, relaunch and verify the selection remains. Check upcoming January/February games, season records and automatic seasonal ordering. The Dev campus picker should appear only for the server-authorized owner account.
- [ ] Switch Light / Dark / Colorful and Forest accent; open the composer, Notes, profiles, Clubs and marketplace. Check larger text, keyboard dismissal and VoiceOver labels as needed.

Remaining features are listed in `2026-11-01-native-functional-parity.md`; passing this checklist does not certify the unfinished backlog or App Store readiness.
