# iPhone posting — October 13 checkpoint

The previous visual checklist was reported passed. These checks cover newly added behavior only. Run them after the updated build is installed; media upload also requires the server release containing the public Storage-origin configuration. Use your own disposable test content.

- [ ] **Composer:** + stays centered and themed in Light, Dark/Forest and Colorful. Whitespace alone does not enable publish. No decorative outlines/shadows.
- [ ] **Drafts:** type text, attach a photo, close by tapping outside, reopen + → Drafts. Text/photo/options survive an app restart. Save draft closes successfully. Deleting a draft removes it. Signing into a different account never shows the first account's drafts.
- [ ] **Photos:** portrait, landscape and small images retain their shape. Select up to six, remove one, reopen the draft. Confirm the published post appears on both website and phone.
- [ ] **Videos:** choose a short portrait and landscape clip. Wait for preparation, publish, and check playback and orientation on website/phone. Oversized files show an error and keep the draft.
- [ ] **HD / 4K:** off initially in Settings; opting in persists after restart. It affects newly selected media; existing draft attachments keep their prepared quality.
- [ ] **Polls:** add a question and two distinct answers without requiring a caption. Add/remove options. Empty/duplicate answers cannot publish. Vote in the feed and verify the server result after refresh.
- [ ] **Visibility/duration:** default is Public + Permanent. Choose Only me or Connections and 24 hours; check the corresponding visibility and expiry on the website.
- [ ] **Retry:** interrupt the connection during upload/posting, reopen the saved draft and retry. One published post should result, with the draft removed only after confirmation.
- [ ] **Leaf feedback:** successful publishing animates the leaf and dismisses; failures stay open with the draft. Reduced Motion uses a short fade.
- [ ] **Social release:** after the pending API release, open Messages/comments/notifications. Test a message/reply/comment with a second account/device, refresh both, and verify private content stays private.

Drafts are local to this iPhone. Camera capture, resolved @ mentions, club/event attachments, GIF/sticker catalogs, cloud draft sync and native realtime remain separate work. No music options are enabled. The automated checks do not replace real upload/two-account checks.
